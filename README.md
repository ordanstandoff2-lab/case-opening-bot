# Case Opening Bot

Discord bot for case opening with random skin drops.

## Setup

1. Create a Discord bot at https://discord.com/developers/applications
2. Set `DISCORD_TOKEN` environment variable
3. Run `npm install && npm start`

## Cases

- **Valor Case**: RARE 59%, EPIC 33%, LEGENDARY 7%, ARCANE 1%
- **Dynasty Case**: RARE 58%, EPIC 33%, LEGENDARY 7%, ARCANE 2%
- **Chameleon Case**: RARE 58%, EPIC 33%, LEGENDARY 7%, ARCANE 2%
- **Division Case**: RARE 58%, EPIC 33%, LEGENDARY 7%, ARCANE 2%

## Usage

Type in Discord: `case valor`, `case dynasty`, `case chameleon`, or `case division`
